# Rules of the City of New York > Title 24: Department of Health and Mental Hygiene > Chapter 12: Window Falls Prevention > § 12-07 Requirement to Install Window Guard.

§ 12-07 Requirement to Install Window Guard.
An owner must install window guards in each window in a dwelling unit for which the owner knows or reasonably should know that there is a child in residence or the occupant requested window guards, including balcony windows, except in the following circumstances:
(a) Windows opening on fire escapes and secondary egress windows. Window guards must not be installed in (1) windows accessing fire escapes or (2) secondary egress windows. In a first floor dwelling unit in a multiple dwelling equipped with fire escapes, the owner may select the window that will serve as the secondary egress window.
(b) Window openings at or below ground level. Where exterior window sills of windows in a dwelling unit are located at or below ground level with less than six inches of drop, window guards are not required.
(c) Emergency escape and rescue openings. Windows defined as required emergency escape and rescue openings in the New York City Building Code and New York City Fire Code must be equipped with devices compliant with ASTM International, F2090-21, Standard specification for Window Fall Prevention Devices With Emergency Escape (Egress) Release Mechanisms, or successor published standard, instead of the window guards otherwise described in this chapter.
(Added City Record 7/23/2025, eff. 1/1/2026)
