# NYC Administrative Code > Title 29: New York City Fire Code > Chapter 2: New York City Fire Code > Chapter 10: Means of Egress > 1002.1 Definitions.

1002.1 Definitions.
The following terms shall, for the purposes of this chapter and as used elsewhere in this code, have the meanings set forth in FC 202.
EMERGENCY ESCAPE AND RESCUE OPENING.
EXIT.
EXIT ACCESS.
EXIT DISCHARGE.
EXIT DISCHARGE, LEVEL OF.
MEANS OF EGRESS.
