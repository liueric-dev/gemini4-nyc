# Housing Maintenance Code Violations NYCHA properties

## Dataset name

Housing Maintenance Code Violations NYCHA properties (Department of Housing Preservation and Development (HPD)).

This dataset displays violations of the New York City Housing Maintenance Code or New York State Multiple Dwelling Law issued by Housing Inspectors pursuant to inspections of NYCHA buildings at the request of the NYC Housing Court.

## Dataset ID

`im9z-53hg`. Portal page: https://data.cityofnewyork.us/d/im9z-53hg

## API URL

`https://data.cityofnewyork.us/resource/im9z-53hg.json` (SODA 2; send `X-App-Token: $NYC_OPENDATA_APP_TOKEN`).

- Update frequency (metadata): Daily; automated: Yes; rows last updated 2026-11-20 09:12.
- Metadata saved: `raw/od-hpd-violations-nycha-metadata.json`.
- Data dictionary: `raw/od-hpd-violations-nycha-dict-nycha-code-violations-data-dictionary.xlsx` (text in `text/`).

## Key fields

| Field | Type | Meaning (from the dataset metadata) |
|---|---|---|
| `viol_seq_no` | number | Unique identifier of Violation |
| `bldg_id` | number | Unique identifier of a building assigned by HPD |
| `development_name` | text | The NYCHA development name. |
| `tds_no` | number | The Tenant Data System number is a unique identifier generated by NYCHA for each development. |
| `bin` | number | The BIN (Building Identification Number) is a unique 7-digit number assigned to every known building by the Department of City Planning (DCP), the first digit of which is the borough code. BINs allow city agencies to process and match building-related data easily and in a consistent manner. |
| `bbl` | number | he BBL (Borough, Block, and Lot) is a combination of three numeric codes - a 1-digit borough number, a block number (up to 5 digits) and a lot number (up to 4 digits) - designated and modified by the Department of Finance (DOF). BBLs are used by various city agencies to identify real estate for taxe |
| `phn` | text | The street number in the building's primary address. E.g.: the house number is '100' in '100 Gold Street' |
| `str_nm` | text | The name of the street in the building's address. E.g.: the street name is 'Gold Street' in '100 Gold Street' |
| `actl_unit_insp` | text | Apartment in violation, if applicable |
| `actl_stry` | text | Floor of violation |
| `viol_desc` | text | Description of the violation |
| `hzrd_clas` | text | The class of a violation describes it’s degree of hazard. In the Housing Maintenance Code, there are three classes of violation: class A (non-hazardous), class B (hazardous) and class C (immediately hazardous). The period in which a landlord is required to correct the condition depends on the class  |
| `insp_dt` | calendar_date | Date when the violating condition was physically observed by a uniformed HPD Housing Inspector. |
| `viol_appr_dt` | calendar_date | Date when the violation was approved to be issued according to HPD's procedures for reviewing/approving violations. |
| `viol_typ_ordr_no` | text | Reference to the abstract description of the violation condition which cites a specific section of the law which is in violation |
| `issued_in_err` | text | "Y" indicates that HPD issued the violation in error. These violation are not considered on record. |

## Caveats

- Only violations issued "pursuant to inspections of NYCHA buildings at the request of the NYC Housing Court" (dataset description). It doesn't cover all conditions in NYCHA buildings.
- Published 2025-09-11 (metadata "Date Made Public"), updated daily.
- Field names differ from `wvxf-dwi5`: `hzrd_clas` = class, `viol_typ_ordr_no` = order number, `viol_desc` = description, `issued_in_err` = `Y` if issued in error (exclude those).
- A NYCHA development shares one BBL across many buildings; query by `bin`.
- License: NYC Open Data. NYC Admin Code § 23-502(d) says public data sets are available "without any registration requirement, license requirement or restrictions on their use", though the city may require apps to identify the source and version (`text/od-nyc-open-data-law-mirror.md`, an unofficial mirror). Dataset metadata has no license field.
- Rate limits: with an app token Socrata "do[es] not throttle API requests ... unless those requests are determined to be abusive"; without one, requests share an IP-based pool with "a much lower throttling limit" (`local/od-socrata-app-tokens.md`). Default page size is 1,000 rows (`local/od-nyc-opendata-api-guide.md`); set `$limit`.
